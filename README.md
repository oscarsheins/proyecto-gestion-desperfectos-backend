# Proyecto Gestión de Desperfectos - Backend

## Puesta en marcha del proyecto

Para ejecutar este proyecto únicamente es necesario clonar o descargar este repositorio.

Dentro de la ruta:

`src/main/resources/documents/sql`

se encuentra el archivo **gestion.sql**.

Importa dicho archivo en tu servidor MySQL para crear la base de datos con toda la información necesaria. Una vez importada, solo tendrás que ejecutar la aplicación Spring Boot y el proyecto estará listo para funcionar.

> **Nota:** Asegúrate de que la configuración de la conexión a la base de datos (`application.properties`) coincide con tu instalación de MySQL (usuario, contraseña, puerto y nombre de la base de datos).
